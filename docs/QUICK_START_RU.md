# Быстрый локальный запуск

Для Windows открой папку проекта и дважды нажми **`start-local.cmd`**. Первый запуск может занять время на сборку. Когда бот ответит, откроется панель `http://127.0.0.1:3000/`. Оставь окно запуска открытым. Чтобы остановить локальную копию, нажми в этом окне **Ctrl+C**.

Если проекта ещё нет на компьютере, клонируй приватный репозиторий `https://github.com/1295pro/ig-replybot-dev`, установи [Rust](https://rustup.rs/), скопируй `.env.example` в `.env.local` и задай `IG_ADMIN_PASSWORD` длиной не менее 32 символов. Файл `.env.local` хранится только на твоём компьютере и не отправляется в GitHub.

## Что нажимать в панели

1. Войди с паролем из `IG_ADMIN_PASSWORD` в своём `.env.local`.
2. Открой **Instagram account**. Если аккаунт уже подключён, проверь его имя; если нет — вставь токен Instagram Professional и нажми **Verify and connect**. Эта проверка не публикует ответы.
3. В **Reply behavior** задай точное слово, публичный ответ и текст DM. Нажми **Save reply rules**. Сохранение настроек само по себе не включает отправку.
4. Проверь в **Control room**, что бот на компьютере остаётся **Paused**, пока работающий сервер отвечает на реальные комментарии. Один аккаунт не следует обрабатывать одновременно двумя активными копиями.
5. Для проверки формы установки можно заполнить адрес сервера и нажать **Read SSH server fingerprint**, затем **Check server**. **Deploy and run checks** создаёт новую копию на VPS; до отдельного решения об установке эту кнопку не нажимай. Уже работающий серверный бот при этом не меняется.

Для настоящего локального теста ответов сначала останови другую активную копию, затем включи локальный бот. После первого успешного опроса оставь **новый** комментарий с точным словом с другого Instagram-аккаунта и проверь публичный ответ и DM. Старые комментарии при первом опросе используются как исходная точка и не получают ответ.

Если браузер не открылся, введи вручную `http://127.0.0.1:3000/`. Адрес работает только на том компьютере, где запущен бот. Если панель не отвечает, посмотри сообщение в окне запуска. Если порт 3000 уже занят другой программой, закрой её перед повторным запуском.
