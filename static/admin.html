Run on this computer

Keep your laptop or home server online and awake. No VPS, domain, or port forwarding is needed with polling.

  1. Download the app for your computer ↗, extract the ZIP, and run the included launcher.
  2. The control room opens and signs you in automatically. Create your own Meta app and generate an Instagram access token.
  3. Connect Instagram below, then save your trigger word, public reply, and DM.
  4. Pause any other copy for the same account, enable this bot, and wait for polling to become healthy.
  5. Leave a new trigger-word comment from another account and confirm both replies.

Settings stay in your user data folder between launches. Public policy and data-deletion pages may be required by Meta; see the setup guide ↗. The controls below manage the bot opened in this tab.

What happens when you install
  • Install Docker from its official repository on Ubuntu/Debian if Docker is missing.
  • Upload only the app source and runtime settings into a new private folder.
  • Build a non-root container with persistent data and a loopback-only admin port.
